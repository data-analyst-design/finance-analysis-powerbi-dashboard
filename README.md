# Finance Analysis Dashboard

## Overview

This project is an end-to-end Business Intelligence solution developed in Power BI to analyze financial transactions, customer behavior, revenue performance, fees, taxes, and regional trends.

The dashboard transforms raw transactional data into actionable insights through data modeling, DAX calculations, and interactive visualizations.

## Objectives

The project aims to answer the following business questions:

- What is the total transaction amount generated?
- Which customer segments contribute the most revenue?
- How do transactions trend over time?
- Which states generate the highest transaction volume?
- Which transaction types contribute most to fees and taxes?
- What is the distribution of transaction statuses?

## Business Insights

- Retail customers contribute the highest transaction volume.
- Successful transactions account for the majority of all transactions.
- Maharashtra generates the highest transaction amount.
- Transaction activity peaks during May and December.
- Loan EMI and Transfer transactions contribute significantly to revenue generation.
