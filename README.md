# Finance Analysis Dashboard (Power BI)

## Project Overview

This project presents an end-to-end Financial Analytics Dashboard built in Power BI.

The dashboard analyzes financial transaction data and provides insights into transaction performance, customer behavior, revenue generation, fees, taxes, and regional trends.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Excel/CSV

## Key Metrics

- Total Amount: ₹135.62M
- Total Transactions: 15.03K
- Average Transaction Value: ₹9.02K
- Total Fees: ₹217.30K
- Total Tax: ₹39.14K

## Dashboard Pages

### Executive Overview

Provides high-level KPIs and business insights.

### Transaction Analysis

Allows detailed exploration of individual transactions.

## Key Insights

- Retail customers contribute the highest transaction volume.
- Successful transactions account for the majority of transaction activity.
- Maharashtra is the top-performing state by transaction amount.
- Monthly transaction trends show seasonal fluctuations.
